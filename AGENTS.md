# Project Guidelines

## Provider icons

- When adding or replacing a provider icon, search [Simple Icons](https://simpleicons.org/) first and use its SVG when the provider is available there.
- If Simple Icons does not include the provider, use an asset from the provider's official website or brand kit and document the exact source in `crates/llmeter-app/assets/providers/SOURCES.md`.
- Do not substitute a parent-company, partner, or adjacent-product logo for the provider's own icon.
- Verify that the icon remains recognizable at the sizes used by LLMeter and on both light and dark backgrounds.
