# Project Guidelines

## Provider icons

- When adding or replacing a provider icon, search [LobeHub Icons](https://icons.lobehub.com/) first and use its provider-specific icon when available.
- If LobeHub Icons does not include the provider, search [Simple Icons](https://simpleicons.org/) and use its SVG when available.
- If neither icon library includes the provider, use an asset from the provider's official website or brand kit.
- Document the exact source and library version, when applicable, in `crates/llmeter-app/assets/providers/SOURCES.md`.
- Do not substitute a parent-company, partner, or adjacent-product logo for the provider's own icon.
- Verify that the icon remains recognizable at the sizes used by LLMeter and on both light and dark backgrounds.
